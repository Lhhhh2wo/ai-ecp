# 智选云 AI 电商在线售货系统（AI-ECP）

> AI E-Commerce Platform · V1.0 · 2026 年 9 月

本仓库为「智选云 AI 电商在线售货系统」的完整成果包，包含可离线浏览的成果站点、两份正式报告、22 幅 UML 图（源文件 + SVG/PNG 渲染图）以及站点构建工具脚本。

**在线访问（GitHub Pages）**：<https://lhhhh2wo.github.io/ai-ecp/>

## 系统简介

支持**智能客服**、**智能选品**、**智能组货**三项 AI 能力的电商在线售货系统，核心特征：

1. **品类自定义（JSON 驱动）**：商品品类结构由商家以 JSON 自定义，系统完成「语法校验 → 语义校验 → 品类树构建 → 衍生能力生成 → 落库发布」，新增品类无需代码变更与发版。
2. **AI 能力内建（能力中台）**：三项 AI 能力共享大模型网关、向量检索、提示词管理与安全护栏。
